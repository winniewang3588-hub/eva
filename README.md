# 東京自由行指南

給第一次去東京自由行的人使用的靜態網站：五天行程範例、區域指南、交通攻略、預算試算、行前清單與在地小提醒。純 HTML、CSS、JavaScript，無建置步驟、無資料庫，可直接以 GitHub Pages 發布，並可安裝成 PWA 離線查看。網站包含東京篇（首頁 `index.html`）、北海道篇（`hokkaido.html`）、九州篇（`kyushu.html`）與名古屋篇（`nagoya.html`），每頁頁首都有「選擇地點」下拉選單可互相切換（`menu.js`）。

## 功能

- **五天經典行程**：Day 1–5 分頁切換（支援方向鍵、Home／End），每天以時間軸列出景點與提醒。
- **區域指南**：12 個區域，可依「美食／購物／文化／夜景／自然」篩選。
- **交通攻略**：成田、羽田進市區方式，IC 卡與地鐵券說明，搭車小訣竅。
- **預算試算**：輸入天數、人數、機票、住宿、餐飲、交通、門票購物與匯率，即時算出日圓花費、全程總計與每人平均。住宿以「天數 − 1」晚計算；匯率需自行輸入最新值，網站不連線查詢匯率。
- **行前清單**：勾選紀錄只存在該裝置瀏覽器的 localStorage（鍵名 `tokyo-trip-checklist:v1`），不會上傳。

### 北海道篇（`hokkaido.html`）

- **六天道央路線**：札幌 → 小樽 → 旭川 → 美瑛 → 富良野 → 札幌，分頁切換（支援方向鍵、Home／End）。
- **四季怎麼玩**：春夏秋冬的看點與穿著建議。
- **區域指南**：11 個區域，可依季節（春／夏／秋／冬）篩選。
- **交通與自駕**：機場進札幌、JR 城市間移動、租車（台灣駕照需日文譯本）、冬季移動注意。
- **必吃美食**與**旅行提醒**。資料寫在 `hokkaido.js`，與東京篇共用 `style.css` 與 `pwa.js`。

### 九州篇（`kyushu.html`）

- **六天北九州路線**：福岡 → 太宰府・柳川 → 由布院 → 別府 → 熊本 → 福岡回程，分頁切換（支援方向鍵、Home／End）。
- **四季怎麼玩**：各季看點與穿著，含梅雨、颱風季提醒。
- **區域指南**：14 個區域，可依「溫泉／美食／歷史／自然／樂園」篩選。
- **交通攻略**：福岡機場進市區、九州新幹線與西九州新幹線、西鐵與高速巴士（SUNQ PASS）、自駕。
- **必吃美食**與**旅行提醒**。資料寫在 `kyushu.js`。

### 名古屋篇（`nagoya.html`）

- **五天名古屋與近郊路線**：名古屋城・榮 → 熱田神宮・大須 → 犬山 → 高山・白川鄉 → 吉卜力公園或名古屋港・回程。
- **四季怎麼玩**：賞櫻、長良川鵜飼、香嵐溪紅葉、白川鄉雪景。
- **區域指南**：15 個區域，可依「歷史／美食／購物／自然／樂園」篩選，含伊勢神宮、高山等近郊。
- **交通攻略**：中部國際機場進市區、地下鐵與一日券、名鐵／近鐵／JR 往近郊。
- **必吃名古屋美食**與**旅行提醒**（名古屋城天守閣不開放、吉卜力公園需預約等）。資料寫在 `nagoya.js`。

### 景點照片

- 各頁「區域指南」卡片顯示景點照片（目前 41 張，部分區域暫無照片），照片資料與出處集中在 `photos.js`，圖檔為 640px 寬的 WebP，放在 `images/<地區>/`。
- 照片皆取自 Wikimedia Commons 的自由授權檔案（CC BY／CC BY-SA／CC0／公有領域），每張照片下方標示作者、授權並連結原始檔案頁；新增或替換照片時必須同樣標示。
- Service Worker 不預先下載全部照片，看過的照片才會存入快取，離線時可再次顯示。

### 花費記帳

- 每頁第 07 區「花費記帳」可隨時新增花費：日期、類別（餐飲／交通／住宿／購物／門票／其他）、項目（選填）與日圓金額（1–10,000,000 的整數）。
- 依匯率即時換算台幣；匯率四個地區共用，修改後所有台幣金額重新計算。統計顯示本地區合計、所有地區合計、本地區各類別與各地區小計。
- 每筆可刪除並可立即「復原」；「清除○○紀錄」會先確認。資料存在瀏覽器 localStorage（`trip-expenses:v1`、`trip-expense-rate:v1`），只在這台裝置、這個瀏覽器，不會上傳；清除瀏覽器資料會一併刪除。離線也能記帳。

### 地點下拉選單

- 頁首的「📍 日本 ▾」按鈕以 `<details>` 製作，沒有 JavaScript 也能展開；`menu.js` 補上點選單外或按 Esc 收合。目前頁面以深底標示並設定 `aria-current="page"`。
- 新增地區頁時，所有頁面的選單項目都要同步加上，並把新檔案加入 `sw.js` 快取清單、遞增版本。

- 內容僅供參考；票價、時刻、營業時間與入境／免稅規定請以官方公告為準。

## 本機預覽

在儲存庫根目錄執行 `python3 -m http.server 8000`，再以瀏覽器開啟 `http://localhost:8000/`。不需要任何外部 CDN 或 API。

## GitHub Pages

合併至 `main` 後，在 GitHub 的 **Settings → Pages → Build and deployment** 選擇 **Deploy from a branch**，分支選 `main`，資料夾選 **/ (root)**。所有資源皆使用相對路徑，適用專案子目錄。

預期網址：<https://winniewang3588-hub.github.io/eva/>。實際可用狀態以 GitHub Pages 部署結果為準。

## PWA：安裝到主畫面與離線瀏覽

- 使用 `manifest.webmanifest`、`sw.js`、`pwa.js` 與 `icons/`，支援 `/eva/` 子路徑。安裝後的 App 名稱為「日本自由行」，圖示為五重塔插圖（自行繪製，無外部授權問題）。
- 已安裝舊版（例如「報修登記」或「東京自由行」）的裝置不一定會自動更新名稱與圖示：Android 通常會在開啟 App 後的一段時間內自動更新；iPhone／iPad 需刪除主畫面上的舊圖示，再從 Safari「分享 → 加入主畫面」重新加入。
- 以 HTTPS（正式網站）或 localhost（開發）開啟一次後，Service Worker 會快取整個介面；之後離線（例如在日本沒網路時）也能開啟並使用所有功能。`file://` 不支援。
- Android Chrome／Edge 符合條件時會出現「安裝到主畫面」按鈕；iPhone／iPad 請用 Safari「分享 → 加入主畫面」。
- 有新版本時顯示「更新指南」，不會自動重新載入。每次變更介面或快取清單都必須遞增 `sw.js` 的 `CACHE_NAME` 版本，並同步更新各頁 HTML 引用 CSS／JS 時的 `?v=` 參數，避免瀏覽器用到舊的快取樣式。
- 本網址先前是報修登記 PWA；新版 Service Worker 啟用時會清除舊的 `repair-pwa:` 快取。舊使用者需按一次「更新」才會換成新版。
